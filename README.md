# tag-writer
An example on using my keyboard to quickly write your username/gamer tag in 4 letters (3 if you use punctuation!) Simple cool tool that can be used to spam your ign, and display your ign on your desk.

Item 1: 1x Seeeduino Xiao Microcontroller 

Item 2: 4x Cherry MX Mechanical Switches 

Item 3: 4x 1U Mechanical Keycaps 

Item 4: 1x Custom Macropad PCB 

Item 5: 1x 3D Printed Enclosure and Plate 

Item 6: 1x USB-C Data Cable
